# All offers in one table, with a status column

## Question

The offers list was split into views (« À examiner », « Retenues », « Écartées », « Toutes »): the user found it unclear, an offer seemed to vanish when it was in another view.

## Decision

One table holds every offer, with a status column (à examiner, retenue, écartée, filtrée, candidature). An offer applied to shows « Candidature », a link to its application. No tabs.

## Why

What is where must be seen at a glance.
