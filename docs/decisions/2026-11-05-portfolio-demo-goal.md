# A public portfolio demo, not a SaaS

## Question

What the project is for, which decides what deserves effort.

## Decision

It is a complete AI application to show in a demo and on a CV, published on public GitHub. It must look good and the code must be clean. Everything committed stays free of personal data.

## Why

For a demo, the visual side has real value, and the project should show an engineer able to deliver an AI project that works and is clean.
