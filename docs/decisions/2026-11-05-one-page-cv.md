# A CV is one page, strictly

## Question

Whether a CV over one page only gets a warning, as in the POC, or is not allowed.

## Decision

One-page CVs only. A longer CV can still be previewed, so that the user can adjust it, but it cannot be downloaded until it fits. Multi-page layouts are not a concern.

Not stated.
